# Xforce Gym — demo website

Single-page animated site for Xforce Gym Pakistan, 205/206 Tulip Commercial, Sector C, Bahria Town, Lahore.

- `index.html` — the whole site (HTML, CSS and JS in one file, no build step)

## Before going live
- Confirm ladies timing (11 am – 3 pm, taken from a Google review) with the owner
- Swap the paraphrased member quotes for real Google reviews, with the owner's OK
- Add real gym photos and the next tournament date

## Deploy on Vercel
Import this repo in Vercel, framework preset "Other", no build command, output directory `./`.
